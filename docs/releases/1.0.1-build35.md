# Super SOL 1.0.1 (35)

## Changes

- Show the approved short grey loading arc after completing the app-access PIN or transfer PIN. Block duplicate input while verification is pending.
- Keep the transfer keypad and bottom actions above Android navigation and gesture insets. Preserve the iOS layout.
- Include the approved interactive PIN-loading demo at `docs/demos/pin-spinner.html`.

## Verification

- Flutter 3.47.5 / Dart 3.13.4: formatting and static analysis of changed Dart files passed.
- Full test suite: 104 passed; four existing golden-test entries failed. The same four failures were reproduced on the previous commit with this SDK; existing golden baselines were not changed.
- Android navigation-inset tests cover compact and tall screens, three-button navigation, gesture navigation, and unchanged iOS layout. The amount screen was also checked on an Android API 37 emulator.

## Release notes

- Xcode Cloud continues to use the existing Flutter 3.32.8 pin and its own CI build number. A successful Git push does not by itself confirm a successful cloud build.
- Android currently uses the existing debug signing configuration for release builds. Do not treat this as a Play Store signing configuration or rotate the key without confirming the customer's installed certificate.
- Previous source revision: `6fce3e577806a155bf791d409d678e8003aca994`. A source rollback should be delivered with a new, higher build number rather than downgrading installed clients.
